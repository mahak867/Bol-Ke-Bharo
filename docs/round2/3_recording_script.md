# 3-minute recording script

**Setup:** Chrome on a laptop, app at http://localhost:8000, sound ON (the app speaks).
Screen recorder: Windows `Win + Alt + R` (Xbox Game Bar), or OBS. Record the whole browser window with mic audio.
Person A = operator, Person B = citizen (an older relative is even better, with consent).
Rehearse twice. If a word is misheard, keep going: correcting it on camera shows the safety net working.

| Time | Do | Say (B, citizen) |
|---|---|---|
| 0:00–0:20 | Title on screen. A says: "Every day lakhs of people get their pension form filled at a CSC. One spelling mismatch and it is rejected weeks later. This is Bol Ke Bharo." | — |
| 0:20 | Click **New application**. App greets aloud. Point at the timer. | — |
| 0:30 | Tap **Citizen bol rahi hain** before each answer. | "जी, मेरा नाम रामवती है" |
| | | "पति का नाम श्याम लाल है" |
| | | "मेरी उम्र अड़सठ साल है" (or "68 साल") |
| | | "महिला" · "बाराबंकी जिले में रहती हूँ" · "फतेहपुर गाँव" |
| | | "मेरा नंबर 98765 43210 है" |
| 1:15 | Point out: full Aadhaar spoken, only last 4 shown. | "आधार 1234 5678 9012" |
| 1:30 | **The wow moment.** Orange warning appears and the app asks aloud which name is right. Pause on it. | "पासबुक पर राम वती लिखा है" |
| 1:45 | Mismatch fixed by voice. | "रामवती सही है" |
| 1:55 | | "SBIN 0001234" · "तीस हजार" · "हाँ, आधार कार्ड है" |
| 2:15 | App reads everything back in Hindi. Let it play a few lines. | "हाँ जी, सब सही है" |
| 2:35 | Status turns **Citizen confirmed**. Click **Export for portal** and show the JSON. Point at the timer. | — |
| 2:45 | A says: "Conversation in, verified application out. Every new form is one JSON file. Audio is not stored, Aadhaar is masked, and a person always does the final submit." | — |
| 2:55 | Show the GitHub repo for two seconds. End. | — |

Show Wispr Flow somewhere, e.g. a 5-second clip of dictating a commit message or README line with it, if it fits.
